Présentation du Langage CSS

Définition : Le CSS (Cascading Style Sheets) est un langage utilisé pour décrire l'apparence et la mise en page des éléments HTML. Il permet de définir des styles (couleurs, polices, marges, positionnement, animations, etc.) pour rendre les pages web visuellement attrayantes et adaptées à différents appareils.

Tout savoir sur son créateur

Le CSS a été créé par Håkon Wium Lie en 1994, alors qu'il travaillait au CERN avec Tim Berners-Lee. Informaticien norvégien né en 1965, il a proposé le CSS pour séparer le contenu HTML de son design. Il a contribué au développement des standards web via le W3C et a travaillé comme CTO chez Opera Software.
