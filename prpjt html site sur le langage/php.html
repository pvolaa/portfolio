Présentation du Langage PHP

Définition : PHP (Hypertext Preprocessor) est un langage de programmation open source, principalement utilisé pour le développement web côté serveur. Initialement créé par Rasmus Lerdorf en 1994, PHP est conçu pour être intégré dans le HTML, ce qui permet de créer des pages web dynamiques et interactives.

Tout savoir sur son créateur

Rasmus Lerdorf, né le 22 novembre 1968 à Qeqertarsuaq, au Groenland, est un informaticien dano-canadien, principalement connu comme le créateur de PHP.
