Projet 2

SITE E-COMMERCE

Description

Ce projet est un site e-commerce, plus précisément un site de vente de peluches, développé en PHP et MySQL. Il permet de se connecter et de faire des achats de peluches de différentes sortes et adaptées aux goûts de tout le monde.

Il n'est pas encore totalement opérationnel mais plusieurs fonctionnalités sont déjà disponibles.

Technologies utilisées

  • PHP
  • MySQL
  • HTML / CSS
  • JavaScript
