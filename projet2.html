Projet 2

Jeu web d'allumettes

Description

Ce projet consiste à développer un jeu web de stratégie dans lequel le joueur affronte l'ordinateur. À chaque tour, le joueur doit retirer entre une et trois allumettes. Le but est de retirer la dernière allumette pour remporter la partie.

Le jeu dispose d'une interface graphique interactive permettant de jouer directement depuis un navigateur, sans installation.

Fonctionnalités

  • Jeu contre l'ordinateur
  • Choix du nombre d'allumettes à retirer
  • Trois niveaux de difficulté : facile, moyen et difficile
  • Gestion des tours du joueur et de l'ordinateur
  • Détection automatique de la victoire et de la défaite
  • Affichage d'un message de fin de partie
  • Possibilité de recommencer ou de quitter la partie
  • Interface graphique adaptée aux différentes tailles d'écran

Technologies utilisées

  • HTML
  • CSS
  • JavaScript

Compétences mobilisées

  • Concevoir et développer une solution applicative
  • Développer une interface utilisateur web
  • Programmer des fonctionnalités interactives en JavaScript
  • Gérer les événements et les interactions utilisateur
  • Tester et corriger les fonctionnalités d'une application
