Projet 1

Site sur les différents types de langages

Description

Ce projet est un site consacré aux langages que l'on peut utiliser en programmation. On y trouve des définitions, des vidéos explicatives et des images de leurs créateurs.

Il a été réalisé en 1re année de BTS SIO (2024-2025) à l'école IRIS, à Paris.

Technologies utilisées

  • HTML / CSS
  • JavaScript

Compétences mobilisées

  • Développer la présence en ligne de l'organisation
