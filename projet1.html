SITE SUR LES DIFFERENTS TYPES DE LANGAGES

Description

Ce projet est un site sur les différents langages qu'on peut utiliser lors de la programmation. Il a été réalisé lors de ma 1ère année en BTS SIO (2024-2025) à l'école IRIS de Paris.
On peut y trouver des définitions, des vidéos et des images des créateurs.

Technologies utilisées

  • HTML / CSS
  • JavaScript
