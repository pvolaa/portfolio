Projet 3

Site e-commerce de labelos

Description

Ce projet est un site e-commerce, plus précisément une boutique de labelos de différentes sortes, adaptées aux goûts de tout le monde. Il est développé en PHP et MySQL et permet de se connecter et de faire des achats.

Fonctionnalités

  • Authentification des utilisateurs (connexion)
  • Catalogue de produits
  • Gestion du panier

Technologies utilisées

  • PHP
  • MySQL
  • HTML / CSS
  • JavaScript

Compétences mobilisées

  • Concevoir et développer une solution applicative
  • Gérer les données
  • Assurer la cybersécurité d'une solution applicative (authentification)
